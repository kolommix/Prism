# Prism

[English](README.md) · **Русский**

Музыкальный плеер для Android и Windows, сделанный для себя и друзей: ваши файлы, темы, эквалайзер, редактор, синхронные тексты и совместное прослушивание.

## Установка

Файлы лежат на [странице релизов](https://github.com/kolommix/Prism/releases/latest).

### Windows 10/11
1. Скачайте **`Prism-Setup-<версия>.exe`**.
2. Запустите. Windows может показать «Система Windows защитила ваш компьютер» (у установщика нет цифровой подписи): нажмите **Подробнее → Выполнить в любом случае**.
3. Права администратора не нужны. Prism ставится только для вашего пользователя, запуск из меню «Пуск» или с рабочего стола.
4. В Prism нажмите **Добавить C:\Users\<вы>\Music** или выберите другую папку.

Удаление: Параметры → Приложения → Prism. Библиотека и настройки остаются в `%APPDATA%\com.kolommix\prism`.

### Android 7+
1. Скачайте **`Prism-<версия>-arm64-v8a.apk`** (почти все телефоны последних лет). Очень старый телефон: `armeabi-v7a`. Не уверены: большой `Prism-<версия>.apk`, он работает везде.
2. Откройте файл. Android попросит **разрешить установку из этого источника**: разрешите, вернитесь и нажмите **Установить**.
3. Откройте Prism, разрешите доступ к **музыке и аудио**, нажмите **Добавить папку**.

Обновления: установите новый APK поверх старого, данные сохранятся. Проверить новую версию: Настройки → О программе.

## Возможности
- **Библиотека**: mp3, flac, m4a, ogg, wav, теги и обложки, поиск, альбомы, исполнители, папки, избранное, плейлисты, умные плейлисты
- **Русский и английский**: как в системе или Настройки → Оформление → Язык
- **Редактор**: волна с масштабом и мини-картой, разрезание, вырезание, перетаскивание фрагментов, дублирование, петля, задом наперёд, склейка песен, скорость 0,25x-4x с плавными переходами, тон, громкость, эквалайзер и шумовой гейт для фрагмента, фейды и кроссфейды, автоматическая обрезка тишины, нормализация, рингтоны; экспорт в mp3 (CBR или VBR), m4a, wav и flac с тегами и обложкой; оригинал не меняется, пока вы сами не выберете замену (с копией)
- **Тексты песен**: плавная подсветка, слова по времени, если они есть в файле, сдвиг для каждой песни
- **Визуализатор**: 10 стилей, определение долей, чувствительность, экономный режим
- **Исправление данных**: поиск в MusicBrainz и iTunes, сравнение бок о бок, сразу для альбома или папки
- **Импорт плейлистов**: Spotify, YouTube, SoundCloud, Deezer, Apple Music, Яндекс Музыка (экспериментально), файлы CSV, JSON и M3U
- **Обмен плейлистами**: код `liner://` или файл `.liner`; друг увидит список, а Prism найдёт песни в его библиотеке и подключённых сервисах
- **Порядок**: выделите несколько песен и перетащите вместе, в начало или в конец, сортировка для каждого плейлиста, ваш порядок сохраняется
- **Статистика**: неделя, месяц, год, всё время, топы, серии, тепловая карта, новое и повторы, «Итоги» как история, карточки можно сохранить картинкой
- **Фоны**: сетка цветов, северное сияние, жидкие капли, звёзды, дождь, снег, зерно, градиенты, ваша картинка или видео, параллакс, затемнение, экономия батареи
- **Слушать вместе**: короткий код, ничего не нужно настраивать, каждый играет песни из своей библиотеки
- **Windows**: мини-плеер, трей, медиаклавиши, статус в Discord. **Android**: виджет, уведомление

## Честно об ограничениях
- **У Яндекс Музыки нет официального API.** Prism использует закрытый, поэтому всё может перестать работать в любой момент, и он отвечает только из некоторых стран (иначе ошибка `451`). **Вживую это ни разу не проверялось**: с компьютера, на котором шла сборка, доступ заблокирован. Если не работает, экспортируйте плейлист в CSV или JSON и импортируйте файл.
- **Spotify** отдаёт только названия песен, небольшое приложение работает для 5 человек. **YouTube**: воспроизведение через неофициальный экстрактор против условий сервиса, по умолчанию выключено, только для себя, может сломаться. Для **SoundCloud** и Google нужны ваши ключи. **Apple Music** читает веб-страницы и тоже может сломаться.
- **Слушать вместе** играет у каждого его собственные файлы; названия песен идут через бесплатный публичный сервер, если это не выключить.
- **Визуализатор в Windows** анализирует файл: он не слышит эквалайзер и скорость и не работает со стримами. **Живой режим на Android** просит разрешение на микрофон, потому что так требует Android; ничего не записывается.
- **Видеофон**: беззвучная петля из первых 30 секунд, 12 кадров в секунду.
- **У установщика нет цифровой подписи**, поэтому Windows предупреждает. В Windows приложение занимает около 260 МБ из-за встроенных аудиоинструментов.
- **Android** проверялся намного меньше, чем Windows. Подробности в `STATUS.md`.

## Онлайн-сервисы
Все сервисы необязательны и включаются по отдельности: Настройки → Сеть и импорт. Ключи хранятся только в локальном файле `online_config.json`, входы в системном хранилище. Подробная настройка в [README.md](README.md).
